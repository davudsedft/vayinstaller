# VAYDNS Manager

یک ابزار ساده و قدرتمند برای نصب و مدیریت VAYDNS روی سرور لینوکس.

## ویژگی‌ها

- ✅ نصب خودکار VAYDNS
- ✅ پشتیبانی از معماری‌های مختلف (x86_64, ARM64, ARMv7)
- ✅ منوی گرافیکی ساده
- ✅ تولید خودکار کلیدهای SSH
- ✅ تنظیم خودکار فایروال
- ✅ نمایش لینک DNS برای کلاینت
